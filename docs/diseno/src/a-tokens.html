Apéndice AEspecificación de tokens de diseño

Este apéndice reúne el conjunto completo de tokens del sistema distintos del color, cuyas escalas se publican en §6.3. Es la referencia operativa: lo que no figura aquí no existe como valor admisible en el producto.

A.1 Estructura del fichero de tokens

Los tokens se mantienen en formato de intercambio estándar, con un fichero por familia y un fichero de alias semánticos. De ahí se generan las propiedades personalizadas de CSS, la configuración del motor de utilidades y la documentación del catálogo. La generación es unidireccional: editar el resultado es un error que el análisis estático detecta.

tokens/
  color.json        // escalas primitivas (§6.3)
  espacio.json
  tipografia.json
  radio.json
  elevacion.json
  movimiento.json
  capa.json
  semantico.json    // alias por intención, con variante clara y oscura

A.6 Ejemplo de serialización y generación

// tokens/semantico.json (extracto)
{
  "color": {
    "texto": {
      "principal": {
        "$type": "color",
        "$value": "{color.neutro.900}",
        "$extensions": { "modo.oscuro": "{color.neutro.100}" },
        "$description": "Texto de lectura y cifras. Contraste verificado ≥ 13:1."
      }
    }
  },
  "espacio": { "4": { "$type": "dimension", "$value": "1rem" } },
  "movimiento": { "estandar": { "$type": "duration", "$value": "220ms" } }
}
// scripts/generar-tokens.ts — contrato del generador
// 1. lee tokens/*.json y resuelve referencias {a.b.c}
// 2. valida que todo alias semántico exista y que no haya ciclos
// 3. comprueba los pares de contraste declarados (§6.9) en ambos modos
// 4. emite styles/tokens.css, tokens.d.ts y la documentación del catálogo
// 5. falla con código distinto de cero si cualquier verificación no pasa
